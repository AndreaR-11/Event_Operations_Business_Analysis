# Event Operations & Business Performance Analysis

## Project Overview

This project analyses the operational and financial performance of a fictional corporate event management business using Excel and MySQL.

The analysis covers 50 event records and examines attendance, delivery formats, client industries, workshop topics, participant feedback and event delays. The objective was to identify performance patterns, highlight operational challenges and develop practical business recommendations based on the results.

## Business Problem

The business needs a clearer understanding of which event formats, corporate-client industries and workshop topics perform best. It also needs to identify operational issues that may affect attendance, participant satisfaction and financial performance.

This project addresses the following questions:

- How is the business performing overall?
- Do online or in-person events deliver better results?
- Which client industries generate the strongest financial contribution?
- Which workshop topics perform best?
- How are event delays associated with attendance, feedback and financial performance?

## Project Objectives

- Assess overall event performance using operational and financial metrics.
- Compare online and in-person delivery formats.
- Identify stronger-performing corporate-client industries.
- Evaluate workshop topics based on attendance, feedback and financial contribution.
- Examine the relationship between event delays and performance.
- Present findings through Excel dashboards, SQL queries and business recommendations.

## Dataset

The project uses a synthetic dataset containing 50 event records.

Each record represents a corporate workshop or event and includes:

| Field | Description |
|---|---|
| Event ID | Unique event identifier |
| Event Date | Date of the event |
| Corporate Client | Fictional corporate client |
| Client Industry | Industry associated with the client |
| Workshop Topic | Subject of the workshop |
| Delivery Format | Online or in-person |
| Registrations | Number of registered participants |
| Attendees | Number of participants who attended |
| Delivery Cost | Event delivery cost |
| Revenue | Revenue generated by the event |
| Feedback Rating | Participant rating out of 5 |
| Delayed Flag | Indicates whether an event was delayed |

**Data note:** All records are synthetic and created for portfolio and analytical practice. They do not represent actual company transactions or client information.

## Tools and Technologies

- **Microsoft Excel:** Data validation, calculated columns, PivotTables and dashboard development.
- **MySQL:** Database management, SQL queries, aggregations and performance analysis.
- **SQL:** Data grouping, filtering, calculations and comparisons.
- **GitHub:** Project documentation and portfolio presentation.

## Methodology

The project was completed in the following stages:

### 1. Data Preparation and Validation

- Imported 50 event records into Excel and MySQL.
- Checked event IDs for duplicates.
- Reviewed attendance counts, feedback ratings and financial values.
- Created calculated metrics in Excel:
  - Attendance Rate
  - Net Contribution
  - Cost per Attendee
  - Revenue per Attendee

### 2. Excel Analysis

Used PivotTables to compare performance across:

- Delivery formats
- Client industries
- Workshop topics
- Event delay status

An Excel dashboard was also developed to present key performance indicators and analytical findings in one place.

### 3. MySQL Analysis

Created a database named `event_operations_analysis` and performed five analyses using SQL aggregation functions, grouping and calculated fields.

The SQL scripts are organised separately for easier review and reuse.

## Analysis and Key Findings

### 1. Overall Business Performance

The 50 events generated AED 142,750 in revenue against AED 68,500 in delivery costs, resulting in AED 74,250 in net contribution.

The overall attendance rate was 81.86%, while average participant feedback was 4.49/5.

**Finding:** The business demonstrated positive overall performance, providing a baseline for further operational and financial comparisons.

### 2. Delivery Format Performance

| Metric | Online | In-person |
|---|---:|---:|
| Events | 28 | 22 |
| Attendance Rate | 83.69% | 78.80% |
| Net Contribution | AED 49,300 | AED 24,950 |
| Average Feedback | 4.59/5 | 4.36/5 |
| Delay Rate | 3.57% | 22.73% |

**Finding:** Online events performed better across attendance, financial contribution, participant feedback and delivery reliability.

### 3. Client Industry Performance

| Industry | Attendance Rate | Net Contribution |
|---|---:|---:|
| Technology | 86.04% | AED 16,750 |
| Financial Services | 85.33% | AED 16,600 |
| Logistics | 84.10% | AED 14,850 |
| Retail | 79.30% | AED 14,750 |
| Healthcare | 72.99% | AED 11,300 |

**Finding:** Technology and Financial Services were the strongest-performing industries. Healthcare showed the weakest attendance and financial contribution, alongside a 50% delay rate.

### 4. Workshop Topic Performance

| Workshop Topic | Attendance Rate | Net Contribution |
|---|---:|---:|
| Excel for Business | 82.10% | AED 16,450 |
| Data Literacy | 82.24% | AED 15,650 |
| AI for Operations | 80.53% | AED 14,700 |
| SQL Basics | 84.67% | AED 13,900 |
| Project Planning | 79.95% | AED 13,550 |

**Finding:** Excel for Business generated the highest net contribution, while SQL Basics achieved the highest attendance rate and participant feedback rating of 4.68/5. Project Planning had the highest delay rate at 20%.

### 5. Impact of Event Delays

| Metric | Not Delayed | Delayed |
|---|---:|---:|
| Events | 44 | 6 |
| Attendance Rate | 83.36% | 67.70% |
| Average Feedback | 4.56/5 | 4.02/5 |
| Net Contribution | AED 68,750 | AED 5,500 |
| Contribution Margin | 54.33% | 33.95% |

**Finding:** Delayed events were associated with lower attendance, participant feedback and net contribution margins. They accounted for five of the six delayed events in Healthcare.

## Business Recommendations

Based on the analysis, the following actions could be considered:

1. **Explore online delivery opportunities:** Online events demonstrated stronger attendance, participant feedback and financial contribution.
2. **Prioritise promising client segments:** Technology and Financial Services showed the strongest overall industry performance.
3. **Review workshop performance:** Maintain the financial performance of Excel for Business while investigating opportunities to expand SQL Basics.
4. **Improve operational planning:** Investigate the reasons behind delays, particularly in Healthcare and in-person events.
5. **Monitor key performance indicators:** Regularly track attendance, participant feedback, contribution and delivery delays to support future decisions.

## Project Limitations

- The dataset contains only 50 synthetic event records.
- The results are intended for analytical demonstration and do not represent actual business performance.
- Financial figures are presented in AED without exchange-rate conversion. The original numerical values have been retained.
- Net contribution is calculated as revenue minus delivery costs and does not account for other business expenses.
- The findings identify patterns and associations, not proven cause-and-effect relationships.
- The six delayed events represent a relatively small sample, so conclusions about delay impact should be interpreted cautiously.
